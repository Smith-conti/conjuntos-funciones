# Proyecto: Teoría de Conjuntos, Relaciones y Funciones  
Aplicación Web en Python con Flask + Bootstrap

Este proyecto implementa los casos prácticos de teoría de conjuntos y funciones usando una interfaz web moderna con Flask, Bootstrap, Matplotlib y Venn Diagrams.

Permite ejecutar:

- Caso 1: Operaciones entre conjuntos (incluye diagramas Venn).
- Caso 2: Funciones evaluadas por separado (cada una en su propia página).
- Gráficas generadas dinámicamente.
